# 🎮 ESP32 Portable Console Deck

Console portátil desenvolvido com **ESP32**, equipado com **display LCD 2.4"**, joystick analógico, botão físico e bateria recarregável.  
Projeto focado em **eletrônica**, **programação embarcada**, **portabilidade** e **estética maker / cyberdeck**.

## 🧠 Sobre o Projeto
Este projeto nasceu da ideia de criar um **console portátil caseiro**, para joguinhos classicos reutilizando componentes acessíveis e explorando ao máximo o potencial do ESP32.

---

## ⚙️ Especificações
- **Microcontrolador:** ESP32
- **Display:** LCD TFT 2.4"
- **Controles:**  
  - Joystick analógico  
  - Botão físico
- **Alimentação:** Bateria recarregável 
- **Construção:** Caseiro / artesanal

---

## 🧩 Componentes Utilizados
- ESP32
- Display LCD TFT 2.4"
- Joystick analógico
- Botões push
- Bateria (Li-ion / LiPo)
- Módulo de carga (ex: TP4056)
- Jumpers, resistores, fios
- Estrutura / case DIY

## 💻 Firmware
- Linguagem: **C / C++**
- Framework: **Arduino / ESP-IDF**
- Comunicação com display via **SPI**
- Leitura analógica do joystick
- Controle de energia e bateria

📁 Código-fonte disponível na pasta `/firmware`.
